📑 Cola de Comandos SQL

Clique em "Executar" em qualquer comando abaixo para rodar e visualizar instantaneamente:

  • -- Query para saber qual campanha converte melhor: SELECT utm_source, COUNT(*) as total_visitas, SUM(CASE WHEN is_converted = true THEN 1 ELSE 0 END) as total_conversoes, ROUND(100.0 * SUM(CASE WHEN is_converted = true THEN 1 ELSE 0 END) / COUNT(*), 2) as taxa_conversao_pct FROM traffic_logs GROUP BY utm_source ORDER BY taxa_conversao_pct DESC;
  • -- Ver ações de um usuário específico: SELECT origem, COUNT(*) as total_acoes, SUM(pontos) as total_pontos FROM historico_ganhos WHERE telegram_id = '8513185549' GROUP BY origem ORDER BY total_acoes DESC;
  • -- Top 5 usuários por tarefas: SELECT nome, telegram_id, tarefas_feitas FROM usuarios ORDER BY tarefas_feitas DESC LIMIT 5;
  • -- Top 5 usuários por indicações: SELECT nome, telegram_id, indicacoes FROM usuarios ORDER BY indicacoes DESC LIMIT 5;
  • -- Diagnóstico de Bloqueios e Retenção (Novas colunas): SELECT COUNT(*) AS total_usuarios, SUM(CASE WHEN status_conta = 'bloqueado' THEN 1 ELSE 0 END) AS total_bloqueados, SUM(CASE WHEN status_conta = 'ativo' OR status_conta IS NULL THEN 1 ELSE 0 END) AS total_ativos, ROUND(AVG(tarefas_feitas), 2) AS media_tarefas_por_usuario, ROUND((SUM(CASE WHEN status_conta = 'bloqueado' THEN 1 ELSE 0 END)::decimal / NULLIF(COUNT(*), 0)) * 100, 2) AS taxa_bloqueio_percentual FROM usuarios;
